# Cost Guide

Every lab declares a structured cost tier. The catalog and CI read the metadata instead of guessing from prose.

| Tier | Meaning | Learner cost |
|------|---------|--------------|
| **GRÁTIS** | Browser-only, simulation, or fully local execution | US$ 0 |
| **GRÁTIS·GH** | Requires only a free GitHub account, Copilot Free, or included public-repository quota | US$ 0 within quota |
| **GRÁTIS*** | Requires eligibility, trial credits, or compatible local hardware | US$ 0 while the condition applies |
| **PAGO** | Requires a license or metered cloud resource | Estimate and cleanup steps required |

**Simulation** is an additional label indicating that a free path exists with mock data or a recorded workflow.

Paid labs must explain the cost driver, provide an estimate, include cleanup steps, and point to the closest free alternative.
