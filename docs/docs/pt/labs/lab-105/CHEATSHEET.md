# MCP Apps: UI Interativa Dentro de Agentes — Cheat Sheet

- Comece pelo contrato local e critérios explícitos.
- Trate prompts, conteúdo recuperado, ferramentas e mensagens como não confiáveis.
- Mantenha identidade, autorização, política, telemetria, custo e limpeza explícitos.
- Prefira a menor orquestração ou adaptação que satisfaça a evidência.
