# Guia de Custos

Todo lab declara uma categoria estruturada de custo. O catálogo e o CI leem os metadados em vez de tentar interpretar o texto.

| Categoria | Significado | Custo para o aluno |
|-----------|-------------|---------------------|
| **GRÁTIS** | Navegador, simulação ou execução totalmente local | US$ 0 |
| **GRÁTIS·GH** | Exige apenas conta GitHub gratuita, Copilot Free ou cota de repositório público | US$ 0 dentro da cota |
| **GRÁTIS*** | Exige elegibilidade, créditos de avaliação ou hardware local compatível | US$ 0 enquanto a condição for válida |
| **PAGO** | Exige licença ou recurso de nuvem medido | Estimativa e limpeza obrigatórias |

**Simulação** é um selo adicional que indica uma trilha gratuita com dados fictícios ou fluxo gravado.

Labs pagos devem explicar o gerador de custo, fornecer estimativa, incluir limpeza e indicar a alternativa gratuita mais próxima.
