# Guide des Coûts

Chaque lab déclare un niveau de coût structuré. Le catalogue et le CI lisent les métadonnées au lieu d'interpréter le texte.

| Niveau | Signification | Coût pour l'apprenant |
|--------|---------------|------------------------|
| **GRÁTIS** | Navigateur, simulation ou exécution entièrement locale | 0 USD |
| **GRÁTIS·GH** | Nécessite uniquement un compte GitHub gratuit, Copilot Free ou un quota de dépôt public | 0 USD dans la limite du quota |
| **GRÁTIS*** | Nécessite une éligibilité, des crédits d'essai ou un matériel local compatible | 0 USD tant que la condition s'applique |
| **PAGO** | Nécessite une licence ou une ressource cloud facturée à l'usage | Estimation et nettoyage obligatoires |

**Simulation** est un label supplémentaire indiquant qu'un parcours gratuit existe avec des données fictives ou un flux enregistré.

Les labs payants doivent expliquer le facteur de coût, fournir une estimation, inclure le nettoyage et indiquer l'alternative gratuite la plus proche.
