# Défis

Les défis sont moins guidés que les labs. Utilisez-les après les labs associés pour prouver que vous pouvez appliquer les concepts sans recette étape par étape.

---

| Défi | Titre | Niveau | Focus | Durée |
|------|-------|--------|-------|-------|
| [Défi 001](challenge-001-agent-loop.md) | Construire une boucle d'agent à partir de zéro | <span class="level-badge level-100">L100</span> | Boucle d'agent, outils, état | ~60 min |

---

## Fonctionnement des défis

- **Commencez par le scénario** et les critères d'acceptation.
- **Téléchargez les fichiers de départ** et lancez les tests.
- **Implémentez uniquement ce qui manque**.
- **Utilisez les indices progressivement** si vous êtes bloqué.
- **Vérifiez la rubrique** avant de considérer votre solution terminée.
