# MCP Apps : interface interactive dans les agents — Cheat Sheet

- Commencez par le contrat local et des critères explicites.
- Traitez prompts, contenu récupéré, outils et messages comme non fiables.
- Rendez identité, autorisation, politique, télémétrie, coût et nettoyage explicites.
- Préférez l'orchestration ou l'adaptation minimale suffisante.
